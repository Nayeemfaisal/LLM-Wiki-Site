Research focus

The research question and the quality gate

  • Question: can time-series measurements be matched to EIS and DRT-ready impedance without guessing missing test context?
  • Gate 1: time, current, voltage, capacity, temperature, or pulse information is present.
  • Gate 2: frequency and complex impedance are present with readable units.
  • Gate 3: cell, test, cycle, SOC, temperature, or protocol metadata can make an honest join.
  • Gate 4: EIS and DRT quality checks pass before interpretation.
New evidence screen

Four sources added with distinct roles

File-manifest candidate

A123 LFP multimodal data

71 cells with paired cell-numbered charge-discharge and EIS files, plus CV, ICA, and PITT. This is the strongest broad multimodal starting point.

Open source
State-matching candidate

LFP EIS and sine-wave pulses

A public LFP collection explicitly combines EIS and short-period sine-wave pulse data. It is a focused candidate for testing state-aware matching.

Open source
Ageing comparison candidate

48-cell degradation indicators

Ageing, pulses, pseudo-OCV, EIS, NFRA, and published DRT peaks create a valuable comparison setting once cell and check-up linkage is audited.

Open source
Quality-control reference

Oxford multisine EIS

Raw current and voltage time series enable independent checks of EIS linearity and stationarity. It is a method reference, not an ageing benchmark.

Backend evidence

What the local API can now demonstrate

  • Job prototype: accepts a local battery CSV, creates a job record, and returns a JSON summary.
  • Single EIS intake: POST /intake/eis checks a CSV before DRT preparation.
  • Batch EIS intake: POST /intake/eis-directory returns one structural report per local CSV.
  • Honest scope: a positive structural report does not replace Kramers-Kronig, reconstruction, residual, stability, or uncertainty checks.
