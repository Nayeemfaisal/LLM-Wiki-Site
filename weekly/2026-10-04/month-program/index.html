This is the execution plan for the next four weeks. It intentionally separates completed audits from planned experiments and treats missing metadata as a result, not an inconvenience.

Research workspace maintained by Nayeem Faisal.

New research frame

Three link levels prevent false matches

  • File coexistence: TS and EIS exist in the same source. Use only for format and parser tests.
  • Cell-level association: both modalities share a cell or test ID. Use for inventory and structural comparison.
  • Event-level match: cell/test, state or SOC, temperature, protocol, and acquisition relationship are documented. Only this level can enter the adapter experiment.

Quality rules

What will make the programme credible

  • Source paths, file hashes, columns, units, and all join decisions are recorded.
  • Missing SOC, temperature, or event linkage blocks model-target creation.
  • Every DRT result includes its settings and an impedance reconstruction check.
  • Negative results remain published, so the work stays reproducible and useful.
