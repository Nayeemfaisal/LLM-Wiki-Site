A123 LFP: clear cell-level link, no proven event-level match

The repository contains time-series and EIS files for the same Cell 1 to Cell 71 index. A raw Cell 1 sample was inspected to determine what can honestly be used in the TS + EIS + DRT pipeline.

Research workspace maintained by Nayeem Faisal.

The README maps both modalities through the same Cell 1 to Cell 71 filename index.

Open gate

State context missing

No sampled field proves the EIS spectrum belongs to a particular cycling segment.

Verified observations

What the sample files actually contain

  • Time-series side: `Stage`, `Current (A)`, and `Voltage (V)` in `Char-dis-Cell1.xlsx`.
  • EIS side: frequency, amplitude, bias, time, real and imaginary impedance, magnitude, phase, and range in `A123-EIS-1.txt`.
  • Cell-level association: source documentation states that all 71 cells underwent the test set, with one corresponding file per cell in each folder.
  • Reproducibility: source paths and SHA-256 checksums are preserved in the audit record.
Research decision

Useful now, but not yet a supervised TS-to-EIS target

  • Allowed: ingestion tests, EIS schema checks, impedance preflight checks, and DRT-input preparation.
  • Not supported: a claim that one EIS spectrum matches a known time window, SOC, temperature, or cycling protocol state.
  • Next evidence gate: obtain source metadata that records state, temperature, test order, and the exact acquisition relationship.
  • Stop rule: retain this as a cell-level multimodal benchmark if an event-level key cannot be documented.
