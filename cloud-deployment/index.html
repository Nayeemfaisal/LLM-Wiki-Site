Deployment sequence

Four controlled steps

01

Access the project

Confirm that the activated GWDG project is visible in Horizon and register a public SSH key.

02

Create the VM

Launch an Ubuntu LTS instance with a small public-web footprint and assign a floating IP if external access is required.

03

Publish safely

Open only the approved web port, deploy the static wiki container, and keep credentials and private data off the server.

Important boundary

What belongs on the public VM

  • Curated public research pages, figures, and supervisor briefings.
  • Not raw restricted datasets, personal information, credentials, or WhatsApp accounts.
  • Any future student/professor communication service needs separate privacy, security, and institutional approval.

The complete deployment instructions are included in the repository under gwdg-cloud/README.md.
