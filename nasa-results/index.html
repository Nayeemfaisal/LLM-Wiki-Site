03

Research use

Decision and limit

What we can and cannot claim today

  • Can claim: NASA is a useful external candidate for a same-cell cycling and impedance study.
  • Cannot claim: a finished TS-to-EIS model or validated DRT comparison.
  • Reason: the inspected records still need an explicit event-level join key and a checked EIS frequency vector before DRT processing.
Next measurable output

Controlled NASA experiment

  1. Create a verified cell ID → cycling record → EIS record pairing table.
  2. Audit units, frequency order, temperature, cycle/state, and measurement timing.
  3. Run EIS quality and reconstruction checks.
  4. Generate EIS-derived DRT curves only for quality-passing spectra.
  5. Compare DRT features with capacity fade, voltage/current features, and cycle number.

This route preserves a clear distinction between source screening, reproducible processing, and a scientific validation claim.
